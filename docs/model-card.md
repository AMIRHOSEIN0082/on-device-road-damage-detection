# Model Card

| مشخصه | مقدار |
|---|---|
| وظیفه | Object Detection |
| کلاس خروجی | `road_damage` |
| فرمت اجرا | TensorFlow Lite FP32 |
| اندازه ورودی | `320 × 320` |
| محل اجرا | Android device |
| نیاز به اینترنت برای Inference | ندارد |
| وضعیت | Demo / Proof of Concept |

## کاربرد موردنظر

نمایش امکان تشخیص زنده خرابی عمومی سطح جاده با اجرای محلی مدل روی موبایل.

## محدودیت‌ها

- مدل تک‌کلاسه است و نوع یا شدت خرابی را مشخص نمی‌کند.
- برای ارزیابی مهندسی روسازی یا کاربرد ایمنی‌حیاتی اعتبارسنجی نشده است.
- دقت عملی به شرایط نور، زاویه دوربین و شباهت داده ورودی به داده آموزشی وابسته است.
