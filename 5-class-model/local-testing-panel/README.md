# پنل تست لوکال — مدل ۵ کلاسه

ابزار Streamlit برای تست سریع مدل تشخیص چندکلاسه خرابی جاده روی سیستم (بدون نیاز به گوشی)، هم با
وزن‌های PyTorch (`.pt`) و هم با همان فایل `.tflite` که داخل اپ اندروید اجرا می‌شود.

## کلاس‌ها

| id | نام | توضیح |
|---|---|---|
| 0 | `longitudinal_crack` | ترک طولی |
| 1 | `transverse_crack` | ترک عرضی |
| 2 | `alligator_crack` | ترک شبکه‌ای |
| 3 | `repair` | وصله/ترمیم — **لزوماً به‌معنای خرابی فعال نیست** |
| 4 | `pothole` | چاله |

## اجرا

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

فایل‌های وزن (`.pt` یا `.tflite`) را در یک پوشه‌ی `weights/` کنار `app.py` قرار دهید — فایل
`.tflite` دقیقاً همان فایلی است که در `app/src/main/assets/` اپ اندروید قرار دارد.

```bash
streamlit run app.py
```

## قابلیت‌ها

- **پخش و پردازش زنده فریم‌به‌فریم** برای ویدیوی آپلودی یا دوربین وبکم.
- **دو بک‌اند قابل انتخاب**: وزن PyTorch (`ultralytics.YOLO`) یا خود فایل `.tflite` موبایل —
  با یک decode دستی (letterbox + argmax روی ۵ کانال کلاس + NMS کلاس‌به‌کلاس) که دقیقاً معادل
  `DetectionMath.decodeAndNms()` در سورس اندروید است، تا نتیجه‌ی این پنل واقعاً قابل مقایسه با
  چیزی باشد که روی گوشی اجرا می‌شود — نه postprocessing عمومی Ultralytics.
- **خروجی ویدیوی annotated** (کدک H.264/`avc1` برای حجم کمتر، با افتادن خودکار روی `mp4v`
  در صورت نبود پشتیبانی H.264 روی سیستم).
- **خروجی PDF فریم‌های تشخیص‌دار**: یک صفحه‌ی خلاصه با جدول تعداد هر کلاس، به‌علاوه یک صفحه به
  ازای هر فریم مثبت (تصویر annotated + کلاس‌های پیدا‌شده در آن فریم). حداکثر تعداد فریم در PDF
  و روشن/خاموش بودن این قابلیت از سایدبار قابل تنظیم است تا حجم فایل برای ویدیوهای طولانی از
  کنترل خارج نشود.

## هشدار

این یک ابزار توسعه/آزمایش داخلی است، نه بخشی از اپ منتشرشده. مدل تک‌کلاسه‌ای که در ریشه‌ی این
مخزن (`docs-single-class/`) معرفی شده هنوز تنها نسخه‌ی رسمی منتشرشده است؛ مدل ۵ کلاسه در این
پوشه هنوز در مرحله‌ی توسعه/ارزیابی داخلی است.
