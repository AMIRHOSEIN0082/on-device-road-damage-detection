# نمونه گزارش واقعی (پنل تست لوکال)

خروجی واقعی یک اجرای پنل تست ([`../local-testing-panel/`](../local-testing-panel/)) روی یک ویدیوی
واقعی رانندگی، برای مدل ۵ کلاسه. هر دو فایل نسبت به خروجی اصلی پنل فشرده شده‌اند تا برای نگهداری
در گیت مناسب باشند؛ محتوا (باکس‌ها، لیبل کلاس‌ها، شمارش‌ها) تغییری نکرده، فقط کیفیت تصویر/رزولوشن
برای کاهش حجم کم شده.

| فایل | حجم اصلی | حجم فشرده‌شده | تغییر |
|---|---|---|---|
| `roadscan_result.mp4` (ویدیوی annotated) | ۴۲۷ مگابایت | ۳۰.۶ مگابایت | H.264 720p به‌جای mpeg4 خام ۱۰۸۰p؛ حدود ۱۴ برابر کوچک‌تر |
| `roadscan_detections.pdf` (۹۷۵ صفحه) | ۸۷ مگابایت | ۲۲.۳ مگابایت | هر صفحه (که خودش یک تصویر کامل JPEG است) با رزولوشن ۶۵٪ و کیفیت پایین‌تر بازفشرده شده؛ حدود ۴ برابر کوچک‌تر |

نکته: این ویدیو ~۱۹۵ ثانیه رانندگی واقعی است و مدل روی ۹۷۴ فریم از آن حداقل یک خرابی تشخیص داده؛
به همین دلیل PDF طبیعتاً پرصفحه است (این گزارش کل مسیر است، نه یک نمونه‌ی کوچک دستچین‌شده).

نسخه‌های به‌روزشده‌ی پنل (بعد از این اجرا) خروجی ویدیو را از ابتدا با H.264 و PDF را با
رزولوشن/کیفیت پایین‌تر می‌سازند — نگاه کنید به [`../local-testing-panel/README.md`](../local-testing-panel/README.md).
