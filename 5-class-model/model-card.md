# Model Card — مدل ۵ کلاسه (در حال توسعه)

| مشخصه | مقدار |
|---|---|
| وظیفه | Object Detection |
| معماری | YOLO11n (Ultralytics) |
| کلاس‌های خروجی | `longitudinal_crack`, `transverse_crack`, `alligator_crack`, `repair`, `pothole` |
| دیتاست آموزش | RDD (Road Damage Dataset) — تقسیم train/val/test مستقل، بدون fine-tune روی داده ایرانی |
| Epochs | ۱۰۰ |
| سخت‌افزار آموزش | ۲ عدد GPU RTX 3080Ti (اجرای multi-GPU) |
| فرمت اجرا روی موبایل | TensorFlow Lite FP32 |
| اندازه ورودی | `320 × 320`، NCHW، نرمال‌شده به بازه‌ی `0..1` |
| شکل خروجی مدل | `[1, 9, 2100]` — کانال‌های ۰ تا ۳ مختصات باکس (در همان فضای پیکسلی ورودی ۳۲۰، نه نرمال‌شده)، کانال‌های ۴ تا ۸ امتیاز خام هر یک از ۵ کلاس (بدون کانال جداگانه‌ی objectness) |
| مسیر export | PyTorch → ONNX → onnx2tf → TensorFlow Lite (مسیر export داخلی/جدید Ultralytics روی این ترکیب نسخه‌ها ناپایدار بود) |
| محل اجرا | Android device، آفلاین (delegate: XNNPACK؛ NNAPI روی برخی دستگاه‌ها fallback می‌خورد) |
| وضعیت | **در حال توسعه / ارزیابی داخلی — هنوز به‌صورت نسخه‌ی رسمی منتشر نشده** |

## نکته‌ی مهم درباره‌ی کلاس `repair`

کلاس `repair` (وصله/ترمیم) به‌معنای وجود خرابی فعال نیست؛ صرفاً نشان‌دهنده‌ی سطحی است که قبلاً
ترمیم شده. در گزارش‌ها و آمار نباید با خرابی‌های فعال (`pothole`, `*_crack`) یکی در نظر گرفته شود.

## محدودیت‌ها

- هنوز روی داده‌ی جاده‌ای ایران fine-tune نشده؛ دقت روی شرایط نوری/بافت آسفالت متفاوت از دیتاست
  آموزش (RDD) ارزیابی نشده است.
- برای ارزیابی مهندسی روسازی یا کاربرد ایمنی‌حیاتی اعتبارسنجی نشده است.
- این مخزن فقط کد پنل تست لوکال (`local-testing-panel/`) را منتشر می‌کند؛ فایل وزن مدل
  (`.pt` / `.tflite`) و دیتاست آموزش بخشی از این مخزن نیستند.
