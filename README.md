# RoadScan — On-Device Road Damage Detection

نسخه دموی اندروید برای تشخیص زنده خرابی‌های قابل مشاهده سطح جاده با اجرای کاملاً محلی مدل هوش مصنوعی روی موبایل.

> این مخزن مخصوص ارائه نسخه اجرایی است. سورس برنامه، دیتاست و فایل مستقل مدل در این مخزن منتشر نشده‌اند.

## قابلیت‌های فعلی

- تحلیل زنده تصویر دوربین عقب
- اجرای مدل TensorFlow Lite روی خود گوشی و بدون اینترنت
- تشخیص تک‌کلاسه `road_damage`
- نمایش Bounding Box و Confidence
- ذخیره فریم‌های مثبت و ایجاد گزارش محلی
- خروجی PDF و CSV
- رابط فارسی با پشتیبانی از حالت عمودی و افقی

## نصب

1. APK را دانلود کنید.
2. در صورت نیاز، اجازه نصب از منبع ناشناس را برای مرورگر یا File Manager فعال کنید.
3. برنامه را نصب و مجوز دوربین را صادر کنید.

این APK یک نسخه Demo/Debug است و برای انتشار در فروشگاه یا استفاده عملیاتی نهایی آماده نشده است.

## محدودیت‌ها

- مدل فعلی فقط وجود خرابی عمومی سطح جاده را تشخیص می‌دهد.
- نوع و شدت دقیق خرابی را تعیین نمی‌کند.
- ثبت GPS واقعی و نمایش رخداد روی نقشه واقعی در این نسخه وجود ندارد.
- Backend، داشبورد وب و ارسال رخداد به سرور پیاده‌سازی نشده است.
- نتیجه به نور، زاویه دوربین، کیفیت تصویر و سخت‌افزار گوشی وابسته است.

## حریم خصوصی

پردازش تصویر در نسخه فعلی روی خود دستگاه انجام می‌شود و برنامه برای تحلیل مدل به اینترنت نیاز ندارد.
